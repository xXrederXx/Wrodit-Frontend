## Lokal Starten

Projekt klonen:

```bash
https://git.bbcag.ch/inf-bl/be/2025/team-h/bbrawn/fullstack/wrodit-frontend.git
```

In das Projekt navigieren

```bash
cd Wrodit-Frontend
```

Projekt starten

```bash
npm i
npm run dev
```

### Voraussetzungen

Für die Lokale Bearbeitung dieses Projekt muss [Node Js](https://nodejs.org/en/download) mit npm installiert sein
